# Método de pesquisa e verificação

1. Formular uma pergunta operacional.
2. Buscar fontes primárias e dados estruturados.
3. Registrar URL, data, país, idioma e contexto.
4. Comparar pelo menos duas fontes independentes quando possível.
5. Separar fato observado de interpretação.
6. Atribuir confiança: baixa, média ou alta.
7. Publicar somente depois de revisão.

## Matriz de evidência

| Campo | Descrição |
|---|---|
| Fato | O que a fonte afirma diretamente |
| Fonte | URL e organização |
| Data | Quando foi publicado/coletado |
| Sinal | Padrão observado |
| Hipótese | Interpretação testável |
| Confiança | Baixa, média ou alta |
| Próximo teste | Ação que pode confirmar/refutar |
